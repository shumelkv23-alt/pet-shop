# Pet Shop

Прототип интернет-магазина товаров для животных. Учебный проект — Практика 2026, Вариант 3.

## Стек

- Vanilla JS (ES-модули)
- Vite
- CSS Custom Properties

## Страницы

| Страница | Описание |
|----------|----------|
| `/` | Каталог товаров с фильтрацией |
| `/product.html` | Карточка товара + похожие товары |
| `/cart.html` | Корзина |

## Запуск

```bash
npm install
npm run dev
```

Сборка для продакшна:

```bash
npm run build
```

## Структура

```
src/
├── data/          # JSON с товарами
├── js/
│   ├── components/  # header, footer, карточка товара
│   ├── pages/       # логика страниц
│   ├── store/       # состояние корзины и каталога
│   └── lib/         # утилиты
└── styles/          # CSS по компонентам
```
